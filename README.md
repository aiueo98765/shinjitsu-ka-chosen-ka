# 真実か挑戦か

通話をつないだまま、合言葉ひとつで同じ卓に着く「真実か挑戦か」。
サーバーを持たない。端末どうしが直接つながる（WebRTC）。

**公開先** … https://aiueo98765.github.io/shinjitsu-ka-chosen-ka/

---

## 遊びかた

1. 通話は別のアプリでつないでおく（Discord・LINE など）。この館は声を扱わない。
2. 誰かが部屋をつくると **6文字の合言葉** が出る。通話で読み上げる。
3. 順番に札が回る。自分の番が来たら **ボタンを押すだけ**。
   真実・挑戦・罰の三つが一つの山に混ざっていて、**種類は選べない**。
4. 出たお題が嫌なら逃げられる。ただし **罰の札** が引かれる。断れない。
   引いた札がはじめから罰だったときは、逃げ道もない。
5. 勝ち負けはない。主が「おひらき」を押すまで回り続ける。

最大6人。挑戦の札は **声とスマホだけで完結する** ものに限ってある。

## つくり

素の HTML / CSS / ES モジュール。ビルド工程はない。

```

  net.js      Trystero の薄い包み。合言葉 → 部屋。リレーの一覧もここ
  game.js     卓の決まりごと（主の端末でだけ動く）
data/
  cards.js    山札のまとめ役
  truth.js    真実
  dare.js     挑戦
  deep.js     深いところ／夜ふかしの議論／生き方／絆／心を渡す
  hot.js      恋（答えるのが恥ずかしい方）／情事ときわどい挑戦（えぐい方）
  hot2.js     恋の増量／きわどい挑戦の増量／送信（卓の外へ本当に送る）
```

### 通信の考えかた

サーバーもデータベースも置かない。Trystero が公開リレー（Nostr）で
**名刺交換だけ** を仲介し、以後のやりとりは端末どうしの直結で流れる。
部屋は `appId + 合言葉` で決まり、`password` に合言葉を渡してあるので、
合言葉を知らない者には中身が読めない。

**リレーは自前で並べる。** Trystero に任せると、47件の山から `appId` の
ハッシュで5件を選ぶ。その5件は `appId` が変わらない限り永久に変わらないので、
5件が朽ちた日にこの館だけが静かに繋がらなくなる。実際そうなっていた。

| 既定で選ばれていた5件 | 状態 |
|---|---|
| slick.mjex.me | 応答なし |
| relay.froth.zone | 接続不可 |
| nostr.tegila.com.br | 繋がるが名刺を運ばない |
| yabu.me | 生きている |
| purplerelay.com | 生きている |

`net.js` の `NOSTR_RELAYS` に8件を並べてある。**繋がるかどうかではなく、
「二人が実際に見つけ合えるか」を一件ずつ確かめたもの**だけを載せている
（damus.io や offchain.pub は繋がるのに見つけ合えないので外した）。

**状態は主（ホスト）が一手に握る。** 山札を引くのも、順番を送るのも主の端末。
客は「引いた」「逃げた」という指図を送るだけで、返ってきた状態を描くだけ。

**誰が主かは、持ち回りではなく毎回その場で計算する。**
「席順で一番前に居る人」が主。誰が数えても同じ答えになるので、
主が落ちても、戻ってきても、全員の見解が食い違わない。
在席の判定も主から配らず、各端末が自分の目で見た繋がり具合から決める。

### 山札

**種類を選ばせない。** 手番の人ができるのは「引く」ことだけで、
真実・挑戦・罰のどれが来るかは `rollKind` が籤で決める。
重みは **真実 42 : 挑戦 42 : 罰 16**。枚数の比（791 : 457 : 54）をそのまま
使うと罰がほとんど顔を出さないので、罰だけは山の厚みから切り離してある。

罰を引いたときは「逃げる」を出さない。**罰に逃げ道はない。**

`used` に引いた札の番号を積み、その種類を使い切るまで同じ札は出ない。
使い切ったらその種類だけ戻す。`p:1` の札（「通話相手」を指す札）は、
主が在席者から一人選んで `対象：〇〇` として札の上に出す。**文面は書き換えない。**

### 罰

`n` がついた札は「縛り」。その巡数だけ効き続け、一巡ごとに残りが減る。
`n` がない札はその場かぎり。

`f` がついた札は「逃げた者にしか意味が通らない」札
（「いま逃げた言い訳を述べる」など）。逃げて引いたときだけ出て、
卓の頭から罰を引き当てたときには伏せてある。

## 札の中身

| 種類 | 分類 | 枚数 |
|---|---|---:|
| 真実 | 恋 | 234 |
| 真実 | 情事 | 174 |
| 真実 | 黒歴史・本音・金と仕事・端末の中 | 125 |
| 真実 | 深いところ・夜ふかしの議論・生き方・絆 | 228 |
| 真実 | 極み | 30 |
| 挑戦 | 声・端末の中・暴露・一発芸 | 182 |
| 挑戦 | きわどい | 125 |
| 挑戦 | 送信 | 45 |
| 挑戦 | 心を渡す | 35 |
| 挑戦 | 端末の奥 | 40 |
| 挑戦 | 極み | 30 |
| 罰 | 縛り・その場かぎり | 54 |
| | **合計** | **1302** |

- **きわどい札**（`r: 1`）は399枚。部屋をつくるときに切ると、山から抜ける（残り903枚）。
- **端末の奥・極み**（`kiwami.js` の100枚）は、履歴や写真をその場で読み上げさせる。
  全部 `r: 1` なので、切れば丸ごと消える。
- **本人提供の52問は原文のまま。** 並べ替えも言い換えもしない
  （`truth.js` / `dare.js` の「ここから下は本人提供」以降）。
- 酒の話題は入れない。
- **送信の札は、刃を送る側にだけ向ける。** 卓にいない人へ本当に届くので、
  受け取った人が傷つく文面（暴言・脅し・不安にさせる嘘）は書かない。

### 札を足すとき

`data/*.js` の配列に一行足すだけ。番号は `cards.js` が並び順から振る。

```js
'新しいお題は？',                      // ただの札
{ x: '通話相手に◯◯する。', p: 1 },     // 相手を名指しする札
{ x: 'いま逃げた理由を言う。', f: 1 },  // 罰のうち、逃げたときしか出さない札
```

きわどい札はその塊の `{ r: 1 }` に入れる。罰の縛りは `{ n: 2 }` の塊へ。

## 手元で動かす

```bash
python scripts/serve.py 8160
```

`http://localhost:8160` を開く。

同じブラウザの別タブどうしで試すときは `?debug` を付ける。
mDNS の候補が解決できずに繋がらない問題を迂回する（**localhost のときだけ**。
本番で効かせると逆に繋がらなくなるため）。`window.__st()` で卓の状態も覗ける。

## つながらないとき

**門は二つある。** 表が Nostr、控えが MQTT。どちらを使うかは人に選ばせない。

- **主** は部屋を開く前に、表のリレーへ手が届くかを確かめる。
  届かなければ黙って控えに回る（帯に「控えの経路」と出る）。
- **客** は席に着けるまで、9秒ごとに門を叩き替える。主がどちらで
  待っているかは客には分からないため。二つとも叩いて駄目なら、
  「合言葉を確かめて、もう一度」の案内が出る。

`?net=nostr` / `?net=mqtt` を付けると、その門に固定できる（叩き替えもしない）。
不具合を切り分けるとき以外は要らない。

**混ざらないようにしてある。** 在席の判定は各端末が見えている相手から決めるので、
一つの卓に二つの門が混ざると、誰が居るかの見解が食い違う。だから主は必ず
どちらか一方に居て、客がそこへ寄っていく。

TURN サーバーは置いていない。両者が対称型 NAT の内側にいる場合
（携帯回線どうしなど）は、門を替えても繋がらないことがある。
これは名刺交換ではなく直結そのものの問題で、リレーでは埋められない。

## 決めごと

- 音は入れない。通話に被るため。合図は札の動きとスマホの振動だけ。
- 日本語は **文節で折る**。`app.js` の `chunkText` が自立語（漢字・カタカナ・
  英数）を塊の頭とみなし、後ろのひらがなを抱かせる。
  「一番静か／に壊れかけて」のような割れ方をさせない。
- 世界観は占いの館（タロット）。日本語＝レトロな太ゴシック（Reggae One）、
  欧文＝アール・デコ調（Cinzel Decorative / Poiret One）。いずれも OFL。
- 会話も内容もどこにも記録しない。札の抽選は各端末の中だけで完結する。
